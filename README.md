# ✦ The Apex Portfolio Network (2026 Edition)

An editorial, high-contrast, multi-persona 3D WebGL portfolio network unifying three defining global icons:
1. **CM Vijay Thalapathy** — Cinema Sovereign turned Chief Minister of Tamil Nadu (Sworn in May 10, 2026).
2. **Pavel Durov** — Billionaire Founder & CEO of Telegram and VKontakte, Digital Sovereignty Pioneer.
3. **Salman Khan** — Undisputed Box Office Titan (₹3,000Cr+ Reign) and Founder of the Being Human & VEER Foundations.

---

## 🏛 Architecture: Main Hub + 3 Sub-Portfolios (5 Pages Each)

- **Main Hub (`/`)**: High-fashion editorial cover with 3 interactive 3D perspective tilt cards, real-time marquee stream, and WebGL particle backdrop.
- **Dedicated Sub-Portfolios**:
  - `/[person]` (**Home**): Interactive 3D Holographic Avatar with speech wave audio guide.
  - `/[person]/journey` (**Journey**): Vertical GSAP ScrollTrigger 3D Timeline detailing life phases from childhood to 2026 status.
  - `/[person]/career` (**Career**): Interactive data grids with box office, user metrics, and statecraft milestones.
  - `/[person]/about` (**About**): Split-screen editorial narrative covering early roots, academic credentials, and humanitarian foundations.
  - `/[person]/contact` (**Contact**): Minimalist glassmorphic PR transmission form and verified social media channels.

---

## ⚡ Tech Stack

- **Core**: React 19, Vite 8
- **3D & WebGL**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animation & Physics**: GSAP, Spring-Physics 3D Card Tilt, Parallax Mouse Tracking
- **Styling**: Tailwind CSS v4, Lucide Icons, Custom Editorial Typography (`Cinzel`, `Syne`, `JetBrains Mono`)
- **Sound & Audio**: Web Audio API Synthesizer (Zero external audio asset dependencies)

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/shah321-glitch/apex-portfolio-network.git

# Navigate to project
cd apex-portfolio-network

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
